### 🎬 Video 1: The Category Teardown (Viral Top-of-Funnel)
* **Target Keyword Cluster:** `Tableau alternative`, `Python vs Rust data science`, `Modern Data Stack broken`, `Local-First analytics`.
* **Title Options:**
  1. *Why I Stopped Using Python & Cloud BI for Data Analytics (And Switched to Pure Rust)*
  2. *The $50,000/Year Cloud Data Mistake (Why We Built DataWeft in Pure Rust)*
* **Thumbnail Concept:**
  * **Visual:** Left side: Red flaming server with "$50,000/mo" label + sad Python logo. Right side: Glowing dark-mode DataWeft studio with "18ms | 100% Local | $0" label + Rust crab logo.
  * **Text Overlay:** *THE DEATH OF CLOUD BI*
* **Video Structure & Script Beats:**
  * **0:00 - 1:15 (The Hook):** Show the pain of waiting 45 seconds for a Pandas DataFrame to load 10M rows vs. DataWeft executing the exact same query in 18 milliseconds on a Mac.
  * **1:15 - 4:00 (The Problem):** Break down the fragmented cloud stack (Fivetran + Snowflake + dbt + Tableau) and the hidden bills draining startup budgets.
  * **4:00 - 8:30 (The Live Demo):** Open DataWeft single binary $\to$ drop CSV $\to$ run 10-Pillar Auto-EDA $\to$ export standalone interactive `.html` report.
  * **8:30 - 10:00 (Call to Action):** Link to the open-source GitHub repository and early beta waitlist.
